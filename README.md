- Project rules: `CLAUDE.md`
- How work is done: `docs/workflow.md`
- Brief and decisions: `docs/project-brief.md`, `docs/decisions.md`

## Setup
After cloning, enable the commit hook:

```
git config core.hooksPath .githooks
```

App setup steps are added by spec 001.
