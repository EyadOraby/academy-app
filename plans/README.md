# Plans

One file per spec, named to match it: `plans/001-project-foundation.md`.

A plan is a numbered list of small tasks. Each task states:
- what to do, in one or two sentences
- the files it may create or change
- how it is verified (the command or test)
- the branch and PR it belongs to

Mark the plan `Status: approved` only after Eyad has read it. No coding before that.
